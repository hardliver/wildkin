### 版權與專利的紅線

- **版權**保護的是具體表現（名字、造型、圖、音樂、文字），**玩法規則本身不受版權保護**。所以：怪物、名稱、美術、劇情、音樂全部原創；用語也避開商標感強的詞（不用「道館」「圖鑑」「寶可夢中心」）
- **專利**才是要小心的：任天堂與寶可夢公司在日本告 Pocketpair 用的專利，涵蓋「在地圖上瞄準丟道具抓怪／放出怪物」「即時顯示捕獲機率」「騎乘怪物飛行、滑翔」
- Wildkin 的抓捕是**戰鬥選單裡選「背包 → 野伴球」**，這是 1996 年就有的 GB 做法，不在上述專利範圍。為了保險，以下不做：
  - 在地圖上瞄準、丟球抓怪或放出怪物
  - 抓之前顯示「成功率 xx%」（球搖晃的動畫可以有）
  - 騎著怪物飛行或滑翔（快速移動改用「營火傳送」）
- 這只是開發上的避險原則，不是法律意見；真的要商業發行時再找專利律師確認

## 2. 世界觀

**舞台：雲根島。** 一座曾經熱鬧、後來被放棄的開拓島。島上的野生生物叫「野伴」，以前的居民和牠們一起種田、蓋房子。

**主角：大志（預設名字，玩家可以改）。** 39 歲，上班族。
- 25 年前，14 歲的他帶著第一隻野伴出門旅行，立志成為「最強的野伴使」。參加了好幾屆大賽，永遠在八強止步
- 後來就是一般人的人生：工作、房貸 20 年、車貸 5 年、未婚，同齡的朋友幾乎都結婚生子了
- 公司組織調整，他拿了優退金。剛好看到「雲根島拓荒計畫：免費配發土地，限 40 歲以下」，**今年是他最後一年有資格**，就報名了
- 名字的由來：「小智」長大變「大志」，也是「胸懷大志」。中年還在追夢，這個名字本身就是笑點

**故事主軸：「夥伴，還是工具？」**（冒險主線不變）
- 「鐵輪公司」也來到島上，把野伴當機器用，關在工廠裡沒日沒夜地工作
- 主角的基地是對照：野伴要吃飽才工作、會累、可以休息
- 結局：關掉鐵輪工廠，被救出來的野伴自願加入你的基地
- 中年的版本多了一層：大志自己就是被公司「優化」的人，看到過勞的野伴特別有感。笑話之外，這是整個故事的情感核心

| 老苔 | 營地的老管理員，七十幾歲，堅持叫大志「年輕人」，這是大志在島上唯一的安慰 |

### 中年笑話：放在哪裡

原則：
- **自嘲，不嘲笑別人。** 笑點是大志自己的處境，未婚、沒買車這些不是缺點，是他的日常
- **穿插，不搶戲。** 冒險、戰鬥的節奏照舊，笑話放在對話、道具說明、系統訊息裡，一個場景最多一兩句
- **病痛只用常見的中年小毛病**（四十肩、老花、尿酸、膽固醇、腰痠），不拿重病開玩笑
- **不改玩法。** 房貸、車貸只是台詞和文字，不會真的扣錢（可能的玩法記在 tasks.md 的「之後」）

**狀態**（全部整數）：
- 灼傷：每回合扣最大 HP // 16，攻擊 // 2
- 麻痺：速度 // 4，每回合 `rnd(4) == 0` 不能動
- 睡眠：1 + `rnd(3)` 回合不能動

**能力階段**（−3～+3）：`能力 × (2 + max(階,0)) // (2 + max(-階,0))`
例：+1 → ×3//2；−2 → ×2//4

## 5. 工作、基地、製作（帕魯的部分）

### 工作特性（8 種，等級 1–3）

- 野外技能需要的野伴**都能在野外抓到**，不會因為初始選擇卡關
- 野伴不用放在隊伍裡也能用野外技能（只要在基地或隊伍裡有）——比 GB 的「秘傳學習器佔招式格」方便

### 時間：用「天」結算，不用真實時間

Comet 沒有系統時間（也不該有，否則網頁和主機結果不一樣）。所以：
- 在營地的床上睡覺 → 過一天 → 結算所有設施產出、隊伍 HP 全滿
- 產出 = 設施基本量 × 派駐野伴的工作等級總和
- 每隻派駐的野伴每天吃 1 份飼料；飼料不夠 → 那隻當天工作量減半（不會死、不會生病，第一版保持溫和）
- 這樣結果完全由存檔決定，重播、連線都一致

## 9. 引擎（Comet）因此要補的

| 功能 | 原因 | 時機 |
|---|---|---|
| 中文文字繪製 | 所有對話、選單（原本的 M2） | M2 |
| 存檔 API（例如 `save(欄位, 字串)`、`load(欄位)`） | 3 個存檔欄位；網頁存瀏覽器、主機存 SD 卡 | M6 |
| **繪圖用調色盤替換**（類似 PICO-8 的 `pal(舊色, 新色)`，只影響之後畫的東西） | 異色野伴、受傷閃爍、夜晚變暗。現在的 `pal` 是改整體顏色，不能只換一隻 | M7 |
| 資料檔合併（JSON → Lua 表格） | 野伴、招式、配方、遭遇表用表格維護，見 Studio 清單 | M4 前 |
| 地圖資料格式 | 地圖編輯器的輸出；Tiny Town 和 Tiny Dungeon 合起來超過 256 格，格子編號要用 2 bytes 或每張地圖指定一張圖 | M3 |

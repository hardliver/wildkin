# Wildkin 野伴 — 遊戲企劃

本文件是**系統**設計（規則、公式）。內容（世界觀、野伴、招式、地圖、章節）見 `content.md`；要做的任務見 `tasks.md`。

## 一句話

2D 俯視角的抓怪冒險：**抓野生怪物、讓牠們在基地幫你工作**，戰鬥是 **Game Boy 時期寶可夢式的回合制**。

## 原則

- **怪物、名稱、美術全部原創**，不使用任天堂、Pocketpair 的名稱與造型
- 美術優先用 **Kenney 免費素材（CC0）**：地圖、角色、道具；Kenney 沒有的（主要是戰鬥用的怪物圖）自己畫
- 回合制戰鬥每回合只交換「選了哪一招」，之後很容易做成連線對戰
- 先在網頁上完成，之後隨 Comet 引擎移植到 Nova One 主機
- **和引擎一起開發**：遊戲缺什麼功能，就回去補引擎

## 核心循環

```
探索地圖 → 草叢遇到野生怪物 → 回合制戰鬥 → 削弱後丟球抓捕
    ↑                                              ↓
用資源做球、蓋設施 ← 基地裡的怪物依特性工作、產出資源 ← 把怪物派到基地
```

## 系統

| 系統 | 內容（第一版） |
|---|---|
| 地圖 | 俯視角 16×16 tile，可捲動；草叢、樹、水、房屋；Kenney Tiny Town。圖層：ground（地面）、deco（房子、柵欄、告示牌）、plants（樹、灌木，會隨風搖）、solid（碰撞） |
| 主角 | 自由移動：搖桿任意角度、推越多走越快（十字鍵也可以）；碰撞只算腳（下半部 10×6 的方框），地圖的 solid 圖層和 NPC 都會擋路、貼牆可滑行、轉角差 4 像素內自動對準；Kenney Tiny Dungeon 的角色（2026-10-18 決定，不採 GB 式一格一格走） |
| 遇敵 | 在草叢裡每走滿 16 像素判斷一次，有機率遇到野生怪物 |
| 戰鬥 | GB 寶可夢式回合制，詳見下方「戰鬥系統」 |
| 抓捕 | 用球抓，對方血越少越容易成功 |
| 隊伍 | 最多 6 隻，可交換出場順序 |
| 基地 | 怪物有「工作特性」（伐木、採礦、種田…），派到基地後隨時間產出資源 |
| 製作 | 用資源做球、回復藥 |
| 存檔 | 存在瀏覽器（主機上存 SD 卡） |
| 怪物 | 第一版 15 種，各有屬性、招式、工作特性（見 content.md） |

## 戰鬥系統

Game Boy 時期寶可夢式的**回合制**：每回合雙方各選一個動作，依速度決定先後。
所有數值都用**整數**計算（Comet 規定），同一場戰鬥在任何平台、重播或連線時結果都一樣。

### 畫面（320 × 240）

```
┌──────────────────────────────────────────┐
│ 敵方名稱  Lv12                 ┌──────┐ │
│ HP ▓▓▓▓▓▓▓░░░                  │ 敵方 │ │  ← 敵方：右上，正面圖 64×64
│                                └──────┘ │
│ ┌──────┐                                 │
│ │ 我方 │                 我方名稱  Lv10  │  ← 我方：左下，背面圖 32×32 放大 2 倍
│ └──────┘                 HP ▓▓▓▓░░ 28/45 │
│                          EXP ▓▓░░░░░░░░  │
├──────────────────────────────────────────┤
│ 野生的 囤囤鼠 出現了！     ▶ 戰鬥  怪物   │  ← 下方：訊息框 + 指令選單
│                              背包  逃跑   │
└──────────────────────────────────────────┘
```

### 一場戰鬥的流程

1. **遭遇**：畫面閃爍轉場 →「野生的 ○○ 出現了！」→ 派出隊伍第一隻
2. **選指令**：戰鬥（選 4 招之一）／怪物（換人，花掉這回合）／背包（球、回復藥）／逃跑
3. **決定先後**：換人、用道具、逃跑一定先動；兩邊都出招時，速度高的先，同速用 `rnd` 決定
4. **執行**：訊息「○○ 使用了 ○○！」→ 被打的一方閃爍、血條慢慢減少 →「效果絕佳！」等提示
5. **倒下判定**：HP 歸零 →「○○ 倒下了！」；敵方倒下得到經驗值，可能升級、學新招
6. **結束**：敵方倒下、抓到、逃跑成功，或我方全部倒下（回到最近的休息點，HP 全滿）

### 數值

| 項目 | 說明 |
|---|---|
| 等級 | 1–50 |
| 能力 | HP、攻擊、防禦、速度（每種怪物有基礎值） |
| 能力公式 | 一般能力 = 基礎值 × 等級 // 50 + 5；HP = 基礎值 × 等級 // 50 + 等級 + 10 |
| 經驗值 | 打倒得到「敵方基礎經驗 × 敵方等級 // 7」；升到 n 級需要 n³ |

### 招式

每招有：名稱、屬性、威力、命中率、可用次數。每隻怪物最多記住 4 招，升級時學新招（滿 4 招時選一招忘掉）。

**傷害公式**（GB 版簡化，全部整數）：

```
基本 = (等級 × 2 // 5 + 2) × 威力 × 攻擊 // 防禦 // 50 + 2
同屬性加成：招式屬性和自己相同 → × 3 // 2
屬性相剋：效果絕佳 × 2；效果不好 // 2；沒有效果 × 0
亂數：× (85 + rnd(16)) // 100
```

命中判定：`rnd(100) < 命中率`。

### 屬性（第一版 6 種）

| 攻擊＼防守 | 普通 | 草 | 火 | 水 | 電 | 岩 |
|---|---|---|---|---|---|---|
| 普通 | | | | | | ½ |
| 草 | | ½ | ½ | 2 | | 2 |
| 火 | | 2 | ½ | ½ | | ½ |
| 水 | | ½ | 2 | ½ | | 2 |
| 電 | | ½ | | 2 | ½ | 0 |
| 岩 | | | 2 | | | |

（空白 = 一般效果）

### 抓捕

用「野伴球」（之後有更好的球）。球的倍率存成「× 2 的整數」：野伴球 2、好球 3、精製球 4。對方血越少越容易抓：

```
值 = (3 × 最大HP − 2 × 目前HP) × 怪物捕獲率 × 球的倍率 // 2 // (3 × 最大HP)
成功：rnd(256) < 值
```

球搖晃 0–3 下的動畫依「值」的大小決定，抓到後怪物進隊伍；隊伍滿 6 隻就送到基地。

### 逃跑

我方速度 ≥ 敵方一定成功；否則成功率隨嘗試次數增加。和訓練家的戰鬥不能逃跑（之後再做）。

### 敵方行動

第一版隨機選一招（`rnd`）；之後再加「優先用效果絕佳的招式」等簡單判斷。

### 為連線對戰預留

戰鬥邏輯寫成「戰鬥狀態 + 雙方選擇 → 下一個戰鬥狀態」，不碰畫面、不碰輸入。
畫面只是把狀態演出來。這樣之後連線時，兩台機器只要交換「選了哪一招」，各自算出一樣的結果。

## 資料檔（data/*.json，W21）

數值都放在 JSON，合併時變成 `DATA.名稱`（見 comet 的 W20）。改完跑 `make check` 檢查彼此對得上。

| 檔案 | 內容 | 遊戲裡 |
|---|---|---|
| `types.json` | 屬性名稱、相剋表 | `DATA.types.names.grass` → "草"；`DATA.types.chart.grass.water` → 4 |
| `moves.json` | 招式：名稱、屬性、威力、命中、次數、說明、效果 | `DATA.moves.leaf` |
| `species.json` | 野伴：名稱、屬性、戰鬥圖格數（`sprite`）、基礎值、捕獲率、基礎經驗、工作、學招表、手冊說明 | `DATA.species["01"]`（編號是兩位數字的字串） |
| `encounters.json` | 每個區域的遇敵率和出現的野伴 | `DATA.encounters.route1` |
| `work.json` | 工作特性的名稱 | `DATA.work.lumber` → "伐木" |
| `trainers.json` | 訓練家：名字、隊伍、視線、台詞（地圖 NPC 的 `trainer` 欄位指到這裡） | `DATA.trainers.rival1` |

約定（全部整數，沒有小數）：
- **相剋倍率用「× 2 的整數」**：4 = 效果絕佳（×2）、2 = 一般、1 = 效果不好（×½）、0 = 沒有效果；表裡沒寫的組合都是 2。傷害計算時 `× 倍率 // 2`
- **招式**：`power` 0 = 不造成傷害（一定要有 `effect`）；`accuracy` 0 = 必定命中；`effect.kind`：
  - `first`：必定先動
  - `stat`：`target`（foe／self）、`stat`（atk／def／spd）、`stages`（−3～+3）
  - `drain`：回復造成傷害的一半
  - `status`：`status`（burn／paralyze／sleep）、`chance`（1–100，%）
- **學招表** `learn`：`[等級, 招式]`，依等級排序；第 1 級至少一招。野生野伴出現時，記住「等級以下最後學會的 4 招」
- **遭遇表** `rate`：每走一格（16 像素）遇敵的機率，以 256 為分母（20 ≈ 8%）；`list` 依 `weight` 權重抽，等級在 `min`～`max` 之間
- **遇敵草叢**：地圖的 `grass` 圖層，有畫的格子就是草叢；遭遇表的名字 = 地圖的名字（`route1` 地圖用 `encounters.json` 的 `route1`）
- 檔案裡不放說明欄位（例如 `_note`）：資料會變成 Lua 表格，多出來的欄位在 `pairs()` 走訪時會被當成資料。說明寫在這裡

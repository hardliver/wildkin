# Wildkin 野伴 — 遊戲企劃

## 一句話

2D 俯視角的抓怪冒險：**抓野生怪物、讓牠們在基地幫你工作**，戰鬥是 **Game Boy 時期寶可夢式的回合制**。

## 原則

- **怪物、名稱、美術全部原創**，不使用任天堂、Pocketpair 的名稱與造型
- 美術優先用 **Kenney 免費素材（CC0）**：地圖、角色、道具；Kenney 沒有的（主要是戰鬥用的怪物圖）自己畫
- 回合制戰鬥每回合只交換「選了哪一招」，之後很容易做成連線對戰
- 先在網頁上完成，之後隨 Comet 引擎移植到 Nova One 主機
- **和引擎一起開發**：遊戲缺什麼功能，就回去補引擎

## 核心循環

```
探索地圖 → 草叢遇到野生怪物 → 回合制戰鬥 → 削弱後丟球抓捕
    ↑                                              ↓
用資源做球、蓋設施 ← 基地裡的怪物依特性工作、產出資源 ← 把怪物派到基地
```

## 系統

| 系統 | 內容（第一版） |
|---|---|
| 地圖 | 俯視角 16×16 tile，可捲動；草叢、樹、水、房屋；Kenney Tiny Town |
| 主角 | 四方向走路動畫；Kenney Tiny Dungeon 的角色 |
| 遇敵 | 在草叢走動時有機率遇到野生怪物 |
| 戰鬥 | GB 寶可夢式：上方敵人、下方我方、血條、選單（戰鬥／怪物／道具／逃跑）、4 招、屬性相剋、經驗與升級 |
| 抓捕 | 用球抓，對方血越少越容易成功 |
| 隊伍 | 最多 6 隻，可交換出場順序 |
| 基地 | 怪物有「工作特性」（伐木、採礦、種田…），派到基地後隨時間產出資源 |
| 製作 | 用資源做球、回復藥 |
| 存檔 | 存在瀏覽器（主機上存 SD 卡） |
| 怪物 | 第一版 8–12 種，各有屬性、招式、工作特性 |

## 引擎（Comet）需要補的功能

| 功能 | 用在 |
|---|---|
| sprite／tile：遊戲檔內嵌圖片資料、每款遊戲自己的調色盤 | 地圖、角色、怪物 |
| 圖片轉換：PNG → 遊戲檔裡的資料（`tools/build.py`） | 把 Kenney 素材放進遊戲 |
| 中文文字：像素字型（俐方體 11 號，OFL） | 選單、對話、怪物名稱 |
| 地圖繪製與捲動 | 大地圖 |
| 存檔 | 進度 |
| 音效（之後） | 戰鬥、腳步 |

# Wildkin 野伴 — 劇本（序章、第 1～3 章、終章）

最後更新：2026-10-21（W53，Neil 已確認）

這份是**要放進遊戲的台詞和劇情流程**。世界觀、角色、笑話原則見 `content.md` 第 2 節；寫法見 `src/scenes.lua`（W52 的劇情工具）。

- 每段劇情一個編號（`P1`、`C1-3`），也是 `SCENE` 表格的名字（`SCENE.p1_arrive`）
- 「觸發」：怎麼開始。事件格（地圖物件 `event`）、跟 NPC 說話、打完戰鬥……
- 「旗標」：劇情做完記在 `FLAGS`，存檔一起存；後面的劇情、NPC 的台詞看旗標決定
- 台詞的一行約 20 個字（對話框寬度），一個 ▸ 是一頁；超過兩行自動分頁
- **中年笑話**照 content.md 的原則：自嘲不嘲笑別人，一個場景最多一兩句，標 😅

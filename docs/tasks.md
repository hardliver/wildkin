# Wildkin 野伴 — 任務清單

最後更新：2026-10-19

把 `design.md`（系統）和 `content.md`（內容）拆成一個一個可以完成的任務，依順序排列。
**一次只做一個任務**；做完打勾、寫上完成日期，再開始下一個。

標籤：
- **[引擎]** 改 `comet`（C 核心、合併工具），在 comet repo commit
- **[Studio]** 改 Comet Studio，編號對應 06 清單
- **[遊戲]** 寫 Wildkin 的 Lua
- **[美術]** 畫圖、畫地圖
- **[企劃]** 決定規則、填資料、平衡

每個里程碑最後一項是「展示」：做到那裡就能停下來、錄影、給人玩。

## M2：畫面上顯示中文

- [x] **W2 [引擎] 中文字型資料**（2026-10-18）
  - 為什麼：完整中文字型好幾 MB，主機放不下；遊戲實際只用到幾百個字
  - 做法：合併工具掃描所有原始碼和資料檔裡出現的字，只把這些字從俐方體 11 號轉成點陣資料，放進遊戲檔
  - 完成：`make` 時印出「用到 N 個字、字型資料 N KB」
- [x] **W3 [引擎] `text()` API**（2026-10-18）
  - 做法：`text(字串, x, y, 色)` 畫 UTF-8 字串，回傳畫完的寬度；英數字半形；更新 AI_GUIDE
  - 完成：`make check` 網頁版與 Mac 版逐像素相同
- [x] **W4 [遊戲] 按鍵工具**（2026-10-18）
  - 為什麼：選單、對話都要「剛按下的那一幀」，每個地方自己記上一幀很容易出錯
  - 做法：在 util.lua 加 `input_update()`（每幀呼叫一次）和 `pressed(鍵)`
- [x] **W5 [遊戲] 對話框**（2026-10-18）
  - 做法：自動換行、超過 2 行分頁、▼ 提示、逐字顯示、按 A 跳到整句／下一頁
  - 完成：畫面上顯示一段 3 頁的中文對話
- [x] **W6 [遊戲] 選單元件**（2026-10-18）
  - 為什麼：戰鬥指令（2×2）、招式、背包、隊伍都是選單，寫一次到處用
  - 做法：給選項列表和排法（直排／2×2），處理游標移動、A 確定、B 取消
